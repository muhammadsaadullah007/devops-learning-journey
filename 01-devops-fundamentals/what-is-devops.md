## 1. What is DevOps?

DevOps is a combination of Development and Operations. It is a culture and set of practices that help development and operations teams work together to deliver software faster and more reliably.

## 2. Why is DevOps Important?

- Improves collaboration between development and operations teams.
- Helps automate repetitive tasks.
- Makes software delivery faster.
- Improves deployment reliability.
- Helps teams identify and resolve problems.

## 3. What Does a DevOps Engineer Do Daily?

A DevOps engineer may:

- Manage servers and infrastructure.
- Automate repetitive tasks.
- Build and maintain CI/CD pipelines.
- Manage cloud infrastructure.
- Work with containers.
- Monitor application performance.
- Troubleshoot deployment issues.

## 4. Key Concepts

- Development: Writing and maintaining application code.
- Operations: Managing the infrastructure where applications run.
- Automation: Using scripts and tools to reduce manual work.
- CI/CD: Automating software integration, testing and delivery.
- Monitoring: Observing application and infrastructure health.

## 5. What I Understood

DevOps is not just a collection of tools. It is a way of improving the complete software delivery process through collaboration, automation and continuous improvement.
